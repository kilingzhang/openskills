# Template System Documentation

OpenSkills now supports customizable templates for generating AGENTS.md files, making it easy to adapt the output for different coding agents (Cursor, Windsurf, Aider, etc.).

## Features

- **Custom Output Path**: Specify any output path and filename (e.g., `.github/rules/AGENTS.mdc`)
- **Flexible Extensions**: No longer restricted to `.md` - use `.mdc`, `.txt`, or any extension
- **Template System**: Use custom templates to format the skills section
- **Configuration File**: Store preferences in `.openskillsrc.json` or `.openskillsrc`

## Usage

### Command Line Options

```bash
# Custom output path
openskills sync --output .github/rules/AGENTS.mdc

# Custom template
openskills sync --template ./my-template.md

# Combine both
openskills sync --output .custom/rules.mdc --template ./templates/agent-template.md

# Use -y flag to skip interactive selection
openskills sync -y --output AGENTS.mdc
```

### Configuration File

Create `.openskillsrc.json` in your project root:

```json
{
  "output": ".github/rules/AGENTS.mdc",
  "template": "templates/custom-template.md",
  "priority": 1
}
```

Then simply run:

```bash
openskills sync
```

Command line options override config file settings.

## Creating Custom Templates

Templates use a simple variable replacement syntax with `{{VARIABLE}}` placeholders.

### Available Variables

- `{{SKILLS}}` - The generated skill XML tags
- `{{PRIORITY}}` - Priority level (default: 1)
- `{{USAGE_INSTRUCTIONS}}` - Instructions on how to use skills
- `{{COMMAND}}` - The command to invoke skills (default: "openskills read")

### Example Template

Create `custom-template.md`:

```markdown
# My Custom Agent Configuration

## Skills System

Priority: {{PRIORITY}}

### How to Use Skills

{{USAGE_INSTRUCTIONS}}

### Available Skills

{{SKILLS}}

---
*Auto-generated by openskills*
```

### Templates for Different Agents

#### Cursor Template

```markdown
# Cursor AI Rules

<skills priority="{{PRIORITY}}">

{{USAGE_INSTRUCTIONS}}

## Skills

{{SKILLS}}

</skills>
```

#### Windsurf Template

```markdown
# Windsurf Agent Configuration

Skills available in this project:

{{SKILLS}}

Usage: {{COMMAND}} <skill-name>
```

#### Aider Template

```markdown
# Aider Skills

You have access to the following skills:

{{SKILLS}}

To use a skill, run: `{{COMMAND}} <skill-name>`
```

## Default Template

If no template is specified, OpenSkills uses the default template that matches Claude Code's format:

```xml
<skills_system priority="{{PRIORITY}}">

## Available Skills

<!-- SKILLS_TABLE_START -->
<usage>
{{USAGE_INSTRUCTIONS}}
</usage>

<available_skills>

{{SKILLS}}

</available_skills>
<!-- SKILLS_TABLE_END -->

</skills_system>
```

## Migration

If you're upgrading from a previous version:

1. No breaking changes - existing commands work as before
2. The `.md` extension restriction has been removed
3. Add a `.openskillsrc.json` file if you want to use configuration
4. Create custom templates as needed

## Advanced Usage

### Multiple Agents

Use different configs for different agents:

```bash
# For Claude Code (default)
openskills sync

# For Cursor
openskills sync --output .cursor/rules.mdc --template templates/cursor.md

# For Windsurf
openskills sync --output .windsurf/AGENTS.md --template templates/windsurf.md
```

### Template Development

1. Start with the default template or one of the examples
2. Customize the structure and styling
3. Use all available variables as needed
4. Test with: `openskills sync -y --template your-template.md`

## Troubleshooting

**Template not found**: Ensure the template path is relative to your current directory or use an absolute path.

**Variables not replaced**: Check that you're using the exact variable names (case-sensitive) with double curly braces.

**Config not loaded**: Verify the config file is in the current directory and is valid JSON.
